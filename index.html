LLM Complaint Intelligence — Semantic Q&A (Static RAG)

Python · NLP · Embeddings · Retrieval (RAG) · GitHub Pages (Static)

This project turns unstructured consumer complaints into a searchable, evidence-based Q&A experience. Instead of deploying an always-on chatbot server, the semantic layer is precomputed offline: complaints are cleaned and normalized, transformed into vector embeddings, and packaged together with lightweight metadata.

At runtime, the web app runs entirely in the browser. User questions are converted into a compact vector representation and matched against the precomputed embedding index to retrieve the most relevant complaint narratives. The app then generates an “LLM-style” answer grounded in the retrieved evidence (top matching complaints), highlighting recurring products, issues, and companies to keep the output practical and auditable.

From a data engineering perspective, this mirrors a production-friendly RAG pipeline: a repeatable offline build step (data prep, vectorization, and export) followed by a zero-infrastructure serving layer. The result is fast, cost-free, and easy to deploy— ideal for portfolio demos and internal knowledge tools.

Key techniques: text normalization, embedding generation, similarity search, evidence-first responses, and static deployment.

Global Air Logistics — Real-Time Network Health

Python · REST APIs · Pandas · Plotly (HTML)

This project demonstrates an end-to-end data engineering workflow applied to global logistics using real-time aviation data as a proxy for international supply chain activity.

Data is ingested directly from a public API and collected in near real time, simulating a streaming scenario commonly found in operational logistics platforms. The pipeline follows a layered architecture (bronze, silver, and gold), focusing on data quality, deduplication, and performance-aware transformations.

At the analytics layer, raw aircraft state vectors are transformed into business-ready metrics such as active aircraft, country-level network activity, operational status (airborne vs. on ground), and traffic trends over time. To ensure smooth web performance, the dataset is selectively aggregated and sampled before visualization.

The final result is an executive-friendly dashboard that provides a real-time view of global air logistics health, combining high-level KPIs with geographic context and interactive filtering. All visualizations are rendered as a standalone HTML application, ready for deployment on GitHub Pages.

Tools & techniques: Python, REST APIs, Pandas, data modeling (fact & dimensions), data quality checks, performance-aware aggregations, Plotly, and static web deployment.
